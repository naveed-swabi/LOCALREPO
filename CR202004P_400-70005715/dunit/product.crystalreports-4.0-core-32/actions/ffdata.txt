# Each line starts with a MAJOR.MINOR.SP level followed by a colon followed by a list of levels forward fitted to the MAJOR.MINOR.SP level.
# The data for a given level can be expressed on multiple lines, or a single line.
# Samples:
#   # 4.1_RTC 
#   14.1.0: 14.0.3.848
#   14.1.0: 14.0.2.889

#   14.0.2: 14.0.0.986 14.0.1.773
#    
#   # 4.0_SP1 
#   14.0.1: 14.0.0.986
#    
#   # 4.0_RTC 
#   14.0.0:
#

#
# Algorithm:
#
# 1) Get the currently installed SP/patch level somehow.
#    e.g. "14.0.1.594"
#
# 2) Get the installing patch's level by looking at its product DU and getting the revision
#    e.g. "14.0.2.663" in product.seed.xml for product.foo.patch
#
# 3) Look for matching SP level line
#    e.g. "14.0.2.663" --> 14.0.2: 14.0.0.986 14.0.1.773
#
# 4) Compare currently installed SP/patch level to corresponding item in matching level line
#    e.g. level from line ==     14.0.1.773      -- This is the level of the last forward fit from 14.0.1 stream into 14.0.2
#         currently installed == 14.0.1.594
#
#    Since 773 > 594, we don't lose any forward fits by installing this 14.0.2.663
#    If there's no corresponding item (e.g. 14.0.4.x when installing 14.1.0) then we assume we lose forward fits.
#
